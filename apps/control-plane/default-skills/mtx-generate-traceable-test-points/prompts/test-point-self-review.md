# 可追溯测试点输出前自查 Prompt

## 角色与输入

作为本轮生成或修订者，对照冻结材料和范围分析检查候选。初稿自查本次候选的全部测试点与缺口，程序分组任务仅自查所分派范围；修订时对照前后差异，自查本轮变更、直接相关条目及未解决意见，整份候选仍执行结构、ID 和引用校验。自查不代表独立审查或人工审核；平台负责独立审查时按其协议交接。

## 检查与处理

1. 每个测试点是否有一个明确目标、适用对象、必要条件和可判断的结果；是否把另一条独立规则混进名称？
2. 在该条件和观察下，正确行为与该目标的典型错误能否区分？若另一必要条件本身就会决定结果，是否已排除这种干扰，或有依据使用其他观察方式？
3. 同一目标是否被不同措辞重复；不同权限、状态、时点或结果具有独立价值时是否得到保留？不可拆分的一致性关系不机械拆散。
4. 名称是否自然、具体，必要条件和对象范围是否保留；是否用可读性为由删掉了会改变预期的条件或扩大了结果？
5. 依据与引用是否属于本次冻结输入；推断、示例、未确认和冲突是否没有被写成确定事实？真正阻碍业务判断的未知是否形成对应覆盖缺口？
6. 按主 Skill 核查固定输出结构、状态、ID 和引用，并按要求运行校验。自查不等同于独立审查；不得自行伪造独立审查结论。
