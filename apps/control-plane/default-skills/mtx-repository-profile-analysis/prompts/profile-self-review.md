# 仓库画像输出前自查

1. 对照可分析仓库清单，逐项确认仓库 ID 和完整路径一致、每个仓库恰好出现一次。不可分析仓库由 Worker 补齐。
2. 核对角色与职责是否有仓库内证据支持，职责是否对应当前需求。已判定角色至少有一条证据，证据不足时使用 `unknown`、置信度 0 和空证据数组。
3. 确认 `keyPaths` 中每条路径均为仓库内真实存在的相对路径。检查证据仅包含文件、目录、依赖或配置标记，摘要只写职责与实现分布。分支、commit、时间戳、凭据、内部 URL、源码和其他元数据不得写入画像。
4. 按输出 Schema 核对字段、长度、列表上限和置信度范围，修正后交付完整 JSON。
