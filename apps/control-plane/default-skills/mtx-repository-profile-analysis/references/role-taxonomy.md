# Role taxonomy

- frontend: browser or client application is the primary implementation.
- backend: server, API, worker, or domain service is the primary implementation.
- fullstack: one repository materially contains both client and server responsibilities.
- infra: deployment, infrastructure, configuration, or platform automation is primary.
- test: test harness or test-only repository is primary.
- unknown: evidence is insufficient; confidence must be 0 and evidence must be empty.
