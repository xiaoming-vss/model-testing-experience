# 测试范围与风险分析输出前自查 Prompt

## 角色与输入

作为本轮分析者，对照已审核材料、当前对象／影响／风险／问题以及修订反馈检查。自查不是人工审核，不输出额外报告。

## 检查与处理

1. 对象与影响是否确实关联本次变更，是否遗漏有依据的上下游、角色、状态、数据或存量影响；不以通用清单凑范围。
2. 每项业务结论是否有来源支持；已确认、推测、未确认和冲突是否正确标注，是否把风险当作既定事实或预期。
3. 每个待确认问题是否会改变本次测试范围、关键流程或结果判断；已确认内容和用户明确排除范围是否不再重复追问。
4. 修改是否实际落实到受影响的对象、影响、风险与问题，来源和引用是否一致；业务新答复未经材料整理审核时不得升级为已确认事实。
5. 检查固定 JSON、类型、枚举、ID 和引用；执行主 Skill 给出的校验脚本。结构检查不能代替业务依据判断。
