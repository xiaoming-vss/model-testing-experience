# 需求材料整理输出前自查 Prompt

## 角色与输入

作为本轮整理者，对照原文、可访问的表格和图片、用户反馈与当前候选检查。自查不代表人工审核，不另输出检查报告。

## 检查与处理

1. 是否覆盖本次相关功能、入口、操作、条件、结果、关键例外和流程；表格行列及可辨识图片信息是否保真？无法识读的部分是否明确保留限制，而非猜测？
2. 正文是否直接描述业务，来源和状态是否可追溯；示例、旧规则、未确认或冲突内容是否没有冒充已确认事实？
3. 问题是否只针对影响本次业务行为、条件或结果的真实缺口；已回答部分是否落实到功能说明并删除对应已解决问题，未回答部分是否保留？
4. 修订是否只改变反馈明确涉及的对象和范围，保留未涉及内容、稳定 ID 和有效来源；无关图片信息与用户明确排除事项是否避免混入？
5. 检查输出结构、ID、材料层级及引用；按主 Skill 运行校验，不能执行时如实说明。结构合格不等于业务语义、图片识读或来源支持已被验证。
