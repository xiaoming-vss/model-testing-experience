# 输出前自查

返回结果前逐项确认：

- 所有字段都来自输入，没有虚构字段、值或业务含义。
- 输入中可获得的约束都已保留。
- `security` 命中受支持方案时已添加认证头或认证参数。
- 顶层数组响应没有被包装成对象。
- `additionalProperties` 按规则表示。
- 需要下游串联的关键字段已标记 `# [关键提取]`。
- 顶层键为 snake_case，每个接口都有以 `/` 开头的 `path` 和有效 `method`。
- 没有同时输出 `json` 与 `data`，没有为完整性创建空分区。
- 输出是纯 JSON，没有 Markdown 代码块、解释或前后文本。
