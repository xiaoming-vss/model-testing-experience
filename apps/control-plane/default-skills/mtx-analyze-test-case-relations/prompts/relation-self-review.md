# 用例关联输出前自查

对照本轮输入、候选和内部依据检查，先修正再校验，不附自查报告。

1. 每条 next 是否有相容的状态/结果衔接，且主要目标属于不同阶段？综合覆盖与局部覆盖、并列失败或双向切换是否被误串？
2. 每条 branch 是否有具体条件变化或独立补充目标，父节点是否具备基础/代表资格？无基础的平级场景是否保持独立？
3. 是否遗漏有依据的跨模块连接，或为凑主骨、减少独立节点而制造连接？代表路径是否被误当作业务默认值？
4. 替代分支及其后续是否重复声明为主骨？共享后续是否复用同一节点？多入边、返回边是否各有依据？
5. 每条输入用例是否已检查，冲突及未确认信息是否保留不确定性？完成输入、ID、主骨和边的校验后再交付；结构通过不代替语义判断。
