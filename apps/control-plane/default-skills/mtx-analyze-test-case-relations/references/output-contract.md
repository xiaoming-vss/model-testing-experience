# 用例关系输出协议 2.0

用于由原始用例直接构成的鱼骨图。字段固定，所有字段必填，不允许额外字段或 null。schema_version 是协议版本，不是用例集版本。

## 字段

| 对象 | 字段 | 类型与含义 |
| --- | --- | --- |
| 顶层 | schema_version | 字符串，固定 "2.0" |
| 顶层 | main_paths | 主骨定义数组，允许 [] |
| 顶层 | edges | 全部直接关联边，允许 [] |
| main_paths[] | path_id | 非空字符串，文件内唯一，例如 P01 |
| main_paths[] | case_ids | 至少两个不重复的原始用例 ID，数组顺序就是主骨顺序 |
| edges[] | edge_id | 非空字符串，文件内唯一，例如 E01 |
| edges[] | from_case_id | 原始用例 ID，关联起点 |
| edges[] | to_case_id | 原始用例 ID，关联终点，与起点不同 |
| edges[] | relation_type | 仅 next 或 branch |
| edges[] | order | 正整数，同一起点所有出线中唯一；不接受布尔值、字符串或小数 |

顶层不重复 case_ids。仅 main_paths 内保留 case_ids。边没有 label；其余未列字段也不输出。

## 图结构与语义

next 表示不同主要阶段的衔接；branch 表示基础/代表场景到有依据的变化或补充场景。具体判定及父节点选择以 [分析方法](../prompts/relation-analysis.md#2-判断-nextbranch-或无明确关系) 为准，两者均不表示测试执行依赖。

- main_paths 仅标识展示主骨，每对相邻 ID 必须存在同方向 next；单节点无需创建主骨。
- 同一有向端点对仅有一条边，禁止自环；允许多入边、多层分支、共享节点及有业务依据的返回边。全图不要求为树或无环，主骨内部不重复用例。
- 禁止重复主骨序列或将已有主骨的连续子路径再次声明为主骨。不同独立链可以共享部分节点或边；分支后续是否具有独立主骨理由由语义复核判断。
- order 只控制同源出边展示顺序，不表示执行、等待、互斥、并发或左右位置，允许不连续。edges 数组的排列不决定关联。
- 不要求所有边或用例从主骨可达；孤立节点及无主骨的关联组件均合法。汇合复用同一 case_id，不表示等待所有前序用例完成。

## ID 与完整性

原始用例是全量节点清单；case_id 和 case_title 不在关联阶段改写。path_id 与 edge_id 在每份图谱内各自全局唯一，跨次生成时可能变化。

用例引用逐字来自本次 cases，不替换、截断或规范化 ID。未出现在关系中的用例由消费者独立展示，不表示删除；分析时仍逐条检查。输入缺失/重复 ID 或缺少完整正文时先澄清。

## 校验边界

`output.schema.json` 保持 2.0 字段结构；完整结构判定使用脚本，还会检查唯一 ID、引用、同源 order、重复端点、主骨 next 衔接及重复/被包含主骨。JSON Schema 将 1.0 视为整数数值，脚本按本协议进一步要求 order 使用整数表示，拒绝小数、布尔值和字符串。

输入用例校验必需字段、非空文本和数组内容，不强制历史用例的字段编号或类别枚举，不拒绝平台附带字段。材料校验 schema、ID、层级和引用；状态/版本配套、业务证据、主骨选择及关系正确性仍由分析者核对。仅运行 schema 或省略输入的结构校验不等于完整交付检查。

## 消费方解析规则

1. 先从原始 cases 建立 case_id → case_title 节点映射，保留完整名称。
2. 校验所有关系引用；未知 ID 报错，不建立占位业务节点。
3. 读取 main_paths 的有序 ID 确定主骨，再根据 edges 建立邻接表。
4. 同源出边按 order 升序。主骨相邻边放在主轴；其他 next 延续所在分支，branch 形成新分叉。对共享节点和回边作图引用，避免无限递归或重复创建用例。
5. 没有入边、出边的原始用例独立展示；多组件不强行连接。

横向或竖向、左右交替、间距、坐标由渲染器确定。此协议保证连接关系明确，不保证不同渲染器像素布局相同。

## 空结果与迁移

没有可确定关系或输入 cases=[]：{"schema_version":"2.0","main_paths":[],"edges":[]}。

旧协议 flows/links 记录业务节点与用例覆盖路径，不能确定用例之间的直接关系。必须结合原始用例重新分析，不能把覆盖相同路径的用例自动串联。校验器拒绝旧版结构，不做隐式迁移。
