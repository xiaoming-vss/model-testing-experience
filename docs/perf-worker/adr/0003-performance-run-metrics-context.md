# ADR 0003：性能运行指标的业务归属与步骤结果

- 状态：已接受
- 日期：2026-11-20
- 取代：—
- 被取代：—
- 关联：[ADR 0002](0002-control-plane-poll-mode.md)、[控制面测试集运行](../../control-plane/adr/0021-performance-suite-serial-execution.md)

## 背景

性能测试集可在多个迭代复用，监控需要关联本次运行的项目、迭代、测试集及用例，并区分请求异常、检查失败和提取失败。控制面拥有业务身份，Worker 只消费冻结规格。

## 决策

测试集运行选择同项目迭代，单用例运行可不选；运行创建时冻结业务身份并下发 Worker。步骤按请求和状态码、响应检查、变量提取的顺序判断，记录首个失败原因。状态码默认接受 2xx，允许显式配置。指标分别记录用例和步骤请求耗时，不聚合不同用例的分位数。

## 后果

新 Worker 接受旧规格中缺省的身份字段；旧 Worker 严格拒绝新增字段，因此部署时先更新并替换 Worker，再启用控制面下发。历史指标不回填。夜莺展示名称需独立维护可授权的名称映射，标签筛选不构成权限隔离。
