# 性能 Worker 领域上下文

本上下文负责把性能运行规格转换为 k6 可执行计划，驱动压测并把事实回传平台。它不持有业务资产、不访问控制面数据库、不承担最终达标判定。

## Language

**性能用例**：
使用 YAML 描述业务步骤、测试数据、负载模型和验收标准的正式测试资产；与 API/UI 用例一样由平台保存、审核和导入。
_Avoid_: 压测脚本、k6 脚本（指用例资产时）

**运行规格**：
一次执行冻结的输入，包含用例内容、环境、Remote Write 配置、执行 ID 和限制；控制面创建运行时组装并加密保存，仅当前租约持有者通过快照接口读取。
_Avoid_: 用例快照、任务参数

**性能运行**：
控制面拥有的执行记录，冻结用例版本、环境、监控接入和数据文件，并保存 Worker 回传的执行事实与控制面运行状态。用户停止、Worker 关闭和租约丢失是不同的事实来源。字段与生命周期以[控制面上下文](../control-plane/CONTEXT.md)的「性能运行」为准；本条描述 Worker 消费和回传的事实边界。
_Avoid_: Worker 任务（指业务运行时）、测试报告

**执行计划**：
编译器从运行规格生成的 `plan.json`，包含 k6 场景、阈值、规范化步骤、数据元信息和允许的环境变量名；它是派生执行产物，不是第二份可编辑格式。
_Avoid_: 用例 JSON、脚本配置

**固定模板**：
随 Worker 版本发布的 `main.js`，读取执行计划并按步骤执行；不为单个用例生成 JS 代码。
_Avoid_: 生成脚本、模板代码（指用户可编辑代码时）

**监控接入**：
平台保存的 Prometheus Remote Write 连接与写入凭据；执行时选择一个，k6 指标写入该接入的 Prometheus。本期平台不保存查询凭据，也不提供查询或外部看板入口。
_Avoid_: 监控配置、监控看板连接

**执行结果**：
Worker 回传的事实，包含生命周期状态、k6 退出码、阈值结果、summary、数据缺失标记和脱敏日志尾部；达标、目标负载未达和监控数据缺失由平台判定。
_Avoid_: 测试报告、性能结论

**运行工作区**：
每次运行独立创建的目录，包含冻结规格、下载的数据文件、执行计划、固定模板、日志和结果；当前保留供本地排查。
_Avoid_: 共享目录、缓存目录

**数据文件**：
项目 S3 中按 `perf_case_data` 用途保存的 CSV/JSON，运行创建时冻结文件 ID、大小和 SHA-256；Worker 通过控制面流式获取，不持有对象存储凭据。
_Avoid_: 测试环境、全局变量

**数据参数**：
用例声明的 CSV/JSON 数据源及分配策略，用于每次迭代取不同行；转换后的数据只在运行工作区存在。
_Avoid_: 测试环境、全局变量

**提取变量**：
步骤从响应中提取、供后续步骤使用的值；只在当前 VU 的当前迭代内有效。
_Avoid_: 全局变量、运行环境变量
