# ADR 0030：历史用例核验以测试点表达补测建议

- 状态：已接受
- 日期：2026-11-26
- 取代：—
- 被取代：—
- 关联：[ADR 0029](0029-historical-test-case-verification-stage.md)、[生成链](../generation-chain.md)

## 背景

历史用例核验负责识别旧用例的维护建议和本轮需要补测的覆盖方向。补测建议需要足以供人工核对业务规则。

## 决策

历史用例核验批次输出 0.2 用一句话陈述补测目标、必要适用条件和可观察结果，并沿用批次关联的规则影响项作为来源。每个测试点是覆盖候选。用例库是否已有对应覆盖仍需根据实际用例确认。Studio 在补测测试点档案中展示目标与来源规则。

## 后果

控制面和 AI Worker 接受历史批次 0.1 和 0.2，外层运行产物继续使用 0.1。Studio 读取旧版批次时用一行展示原操作和预期，完整旧产物可在 JSON 中查阅。发布新版历史核验 Skill 前，部署兼容的控制面与 AI Worker；Studio 随代码发布。
