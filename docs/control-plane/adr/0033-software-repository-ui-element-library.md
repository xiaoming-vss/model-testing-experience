# ADR 0033 软件仓库拥有元素库

- 状态：已接受
- 日期：2026-11-26
- 取代：—
- 被取代：—
- 关联：[ADR 0015](0015-software-repository-direct-gitlab-binding.md)、[ADR 0014](0014-pre-release-single-baseline.md)

## 背景

同一前端应用的多个页面和业务流程需要复用经过维护的 UI 元素。元素定位可引用运行时业务值，例如在订单表格中定位指定订单行里的编辑按钮。

## 决策

- 首版一个软件仓库对应一个前端应用。控制面保存仓库级页面分组、唯一公共组和元素。Studio 在资产库中提供元素库页签。
- 页面组按应用内路由模板唯一，公共组供该应用跨页面共享。元素按分组、作用范围、定位类型和定位模板查重，数据库使用定位摘要保证唯一。仓库或分组的删除受子资源约束，有元素库分组的仓库保留其 GitLab 仓库身份。
- 元素保存定位模板及参数定义。模板使用现有 UI 定位变量语法。手工维护的元素初始为待验证。元素编辑使用版本检查。
- 首版提供查询和手工维护。后续浏览器捕获、验证和 UI 用例生成消费元素库，需要各自确认任务与快照契约。

## 后果

元素库读取与维护复用项目权限。控制面和 Studio 消费首版接口。表结构进入预发布唯一 Alembic 基线，空库初始化会创建元素库表。当前生产契约见[元素库接口](../ui-element-library.md)。
