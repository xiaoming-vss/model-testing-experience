# 共享服务配置与个人授权分离

项目成员需要看到相同的 LLM、禅道和 GitLab 服务目录，同时仍必须使用各自的外部凭据。服务配置因此独立于个人连接：所有者先创建不含凭据的项目共享服务，每名成员再单独授权；未授权也能查看服务，但无法使用他人的连接。共享列表只投影当前人的授权状态，不暴露其他成员的账号、授权记录或凭据。

这细化了 ADR-0007 的个人授权边界，取代基础服务列表仅显示个人连接的交互。代价是增加服务与个人连接之间的关联；已有执行流程继续引用个人连接 ID，保持任务归属和凭据隔离。新服务地址与模型在创建后固定，避免修改共享地址时把已有成员的凭据发送到新服务；需要更换时创建新的服务并重新授权。服务删除会使其全部个人连接失效；撤销个人授权只影响本人。

部署仅支持新空库初始化，不提供旧库升级工具，也不将历史个人连接转换为共享服务或授权。共享服务及个人授权由用户通过相应接口显式创建。新页面使用服务目录与独立授权接口；个人连接接口继续供执行选择器和兼容调用使用，对已关联服务的连接禁止修改公共配置。
