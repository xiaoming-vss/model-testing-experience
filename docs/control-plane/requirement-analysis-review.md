# 需求分析运行的审核与拒绝

2026-10-07，用户明确确认已拒绝的需求分析运行作为只读终态：只能查看产物或删除运行记录；重新生成发起新运行。该规则适用于材料提取与需求理解的审核，不调整其他任务类型。

仅待审核产物可以执行审核。最终需求理解被拒绝后，生成状态为 success、阶段执行状态为 completed，审核状态为 rejected：生成完成与审核通过是两种状态。拒绝结果不再占用 waiting_review。材料阶段拒绝仍按原有取消流程结束。

保存、审核及 AI 修订入口在状态变更前统一拒绝已拒绝运行，返回既有400错误信封，提示仅支持查看或删除并重新运行任务。重试仍只允许失败执行且审核状态为 pending；导入仍要求 approved。已有已批准产物的编辑及重新审核规则保留。

Studio 的行内审核、产物弹框、原始 JSON、优化及重试入口使用对应状态条件；拒绝结果的弹框为只读，顶部也不提供导入。查看较早的运行时，弹框绑定运行 ID，避免切换选择时立即关闭。

验证覆盖服务层无状态改写/无入队、保存/审核/修订/重试/导入HTTP拒绝、待审核最终拒绝收尾、只读JSON、运行历史入口和首次打开旧产物。没有数据库结构或协议字段变更。AiRunView 声明已有临时审核重置标记的类型，供类型检查使用；该标记不映射为数据库列。
