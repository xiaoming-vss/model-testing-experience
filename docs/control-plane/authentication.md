# 登录与服务端注销

浏览器使用 `Authorization: Bearer <JWT>` 访问业务接口。JWT 使用 HS256 签名，包含用户身份、到期时间和每次登录独立的 `jti`；默认有效期仍为 168 小时。

`POST /v1/logout` 使用当前请求的 Token 注销该登录会话。服务端在提交数据库事务后返回成功；随后携带这个 Token 的业务请求返回 401。同一用户的其他登录会话继续有效。已签发且没有 `jti` 的旧版 Token 同样可以注销。过期、已撤销、无效或未提供 Token 的请求返回 401。

撤销记录保存在 `revoked_access_tokens`，只保存 Token 的 SHA-256 摘要、用户 ID 和到期时间，不保存原始 Token。业务接口在查询用户身份时同时检查撤销记录，因此多个后端进程和服务重启共享相同的撤销结果。每次注销清理已到期的撤销记录；删除用户时级联删除该用户的记录。

部署包含这项改动的后端前，执行数据库迁移：

```sh
python3 scripts/manage.py migrate
```

迁移 `20261003_0024` 新增撤销记录表，不改写现有用户或 Token。回退该迁移会丢弃撤销记录，仍未过期的旧 Token 可能重新有效，生产环境应保留这项迁移。

Studio 的退出按钮先调用服务端注销，成功后清除浏览器 Token、用户状态和查询缓存。服务端返回 401 时也清理本地状态；网络错误或服务端其他错误保留登录状态并提示重试。请求遇到 401 时的自动本地清理不再次调用注销接口。退出登录不会取消已提交的后台任务，任务权限仍按运行发起者的项目角色与个人授权检查。


功能候选导入要求运行所在项目的执行权限与目标需求的写权限，包含首次导入和覆盖确认。只读成员只能查看候选结果。AI 任务的需求与迭代必须属于任务所在项目；同时指定需求与迭代时，两者必须匹配。创建、读取、更新、执行及运行详情均校验归属，历史错误关联也会被拒绝。任务列表批量加载归属字段，不读取需求正文。

共享服务查询不获取项目或服务的写锁；配置修改和个人授权保存仍使用事务锁。MCP 身份查询在授权写事务前完成，进入写事务后重新校验权限与服务地址，避免远程等待长时间占用项目锁。

`core/errors.py` 的命名错误对象用于保存错误码、消息与 HTTP 状态。抛出时使用 `raise ErrNotFound()` 等调用形式创建本次请求的异常实例，避免共享对象累积其他请求的堆栈；响应契约保持一致。
