# LDAP 统一认证

本功能以 Synology LDAP Server Provider 为目标。当前环境已完成登录及管理员停用／恢复状态验证；临时锁定、密码过期、到期状态等未实测项仍需按实际目录验收，不能由模拟测试替代。

## 身份与账号规则

LDAP 开启后关闭自助注册，本地登录只供唯一超级管理员使用。登录请求新增 `authMethod: local | ldap`，省略仍按本地处理，任何失败均不回退到另一种认证方式。匿名 `GET /v1/auth/config` 只返回 `ldapEnabled`、`registrationEnabled`、`localLoginAdminOnly`，不访问目录或公开连接参数。

关联依据为规范化的 `entryUUID`；迁移窗口内可显式开启 `auto_link_by_username`，将同名的普通待关联本地账号关联到目录，保留原 `user_id`、项目、角色与个人授权。关联原子清空本地密码、递增 Token 版本并转为正常。禁用及有效锁定不能由关联解除。没有人工关联、批量预关联、身份覆盖或合并工具。

用户名随目录登录成功时同步；非空邮箱同时同步，空邮箱保留存量值，新建账号要求邮箱非空。资料冲突拒绝此次登录并整体回滚，不撤销既有会话。已关联用户返回 `authSource=ldap`，本人及管理员不能修改身份资料或重置密码；管理员保留禁用、启用、强制下线和删除。关闭 LDAP 不恢复密码及本地身份。

LDAP 默认固定会话 12 小时，管理员仍为 24 小时。密码错误沿用现有阈值；LDAP 和本地入口分别限流，目录故障、组外或明确禁用不计密码错误。LDAP 密码不套用 bcrypt 长度限制，空密码不发起 bind。

## 配置与目录验收

管理员在头像菜单的「LDAP 认证」（`/admin/ldap`）管理配置，数据库 `auth_runtime.ldap_config` 为唯一来源。数据库尚未配置时 LDAP 默认关闭，页面提供空连接参数及默认策略；不读取或导入旧文件参数。

- `server_url`、查询账号、用户范围、专用访问组需部署时填写。查询账号不自动取得平台访问资格。只认可专用组直接成员，不递归嵌套，也不使用主组作为替代。
- `memberUid/username` 与 `member/dn` 二选一。DN 成员使用目录 LDAP Compare 的匹配规则。组类型及 ACL 必须验证；尤其要证明不可读与真实空组可以正确区分。
- `entryUUID` 显式请求并按 UUID 文本归一化；没有属性或结果不完整返回 503。查询用户和验证密码采用独立连接，不写目录。
- `active_user_filter`、`disabled_user_filter` 是在用户当前 DN 上执行的两条互斥状态过滤器。必须使用实际套件验证正常、管理员禁用、到期禁用、临时锁定和密码过期。临时锁定或密码过期不应被映射成持久禁用；不预填 AD 属性或猜测群晖属性。
- `directory_rules_verified=false` 是默认状态，此时 LDAP 认证及对账均拒绝执行。只有完成状态规则和查询账号读取/比较权限验证后才能设为 `true`。过滤器判断同时命中或均不命中为无法判断，返回 503，对账不改账号。
- 明文必须同时配置 `ldap://`、`start_tls=false`、`allow_insecure_connection=true`；生产也可显式选择。LDAPS 应设置 `start_tls=false`。TLS 始终校验证书和服务器名称，不提供跳过验证或明文回退。
- 私有 CA 在页面粘贴 PEM 公钥证书；留空使用系统信任库。已有数据库配置中的 CA 文件路径继续兼容，部署配置文件不再生成 LDAP CA 挂载。

页面保存的查询密码使用现有 `integration_key` 加密存储，不返回浏览器，不写入用户表、命令参数或日志；应随数据库备份妥善保管该加密密钥。查询密码仅通过管理员页面设置。运行配置及 Compose 覆盖文件位于忽略路径，不提交仓库。

## 页面配置（推荐）

部署迁移 0043 后，使用唯一超级管理员本地登录，在头像菜单打开「LDAP 认证」。页面会带入数据库中保存的连接与状态规则，密码仅显示是否已设置。普通用户无权读取、测试或保存配置。

1. 填写地址、查询 DN、用户搜索范围、访问组以及连接方式。群晖 `memberUid` 组按用户名匹配。高级设置保留已验收的身份属性、状态过滤器、迁移窗口和对账周期。
2. 可点击「检查连接」验证查询账号、搜索范围和访问组；填写用户名还会检查访问资格与邮箱。检查使用当前表单，不保存配置，不验证用户密码。
3. 点击「保存并生效」；启用或关闭需要确认影响。保存与认证模式切换在同一数据库事务中完成，登录及对账自动使用新配置，无需重启、停流或另行执行 CLI。所有实例必须先升级到支持页面配置的版本。
4. 密码留空保留旧值，输入新值会替换。关闭 LDAP 时可在高级设置显式清除密码。两个管理员页面同时修改时，旧版本保存返回冲突，重新加载后再编辑。

启用会将正常普通本地账号改为待关联并撤销普通旧会话，原禁用记录及管理员保持不变。关闭不会恢复待关联账号、LDAP 身份或已清空的本地密码。配置更新通过版本校验阻止旧配置登录／对账结果提交；仅修改配置不重复撤销已建立的用户会话。

页面支持粘贴私有 CA 的 PEM 公钥证书，优先于旧 `tls_ca_file`，适用于容器部署。留空沿用旧 CA 文件或系统信任库；不接受私钥。TLS 失败不回退明文。

旧文件切换 CLI 已停用，所有配置均从页面管理。管理员本地登录保留；加密密钥变更导致密码不可读时，可重新输入查询密码保存修复。迁移 0043 不会自动导入密码或改变认证模式；存在页面配置时禁止直接降级删除该列。

## 定时对账

默认 300 秒运行一次，只检查平台已有 LDAP 身份。数据库租约保证同一时刻只有一个有效对账；目录等待不持有用户写锁。整轮目录查询、范围与身份结果完整成功后，重新核对配置版本、租约及本地账号版本，才将确认删除、禁用或移出组的正常账号禁用。

自动禁用只记录“LDAP 对账禁用”、时间及空操作人，递增 Token 版本。不会清理个人授权、项目成员或终止已提交任务。重复对账不覆盖已有禁用记录，不同步姓名邮箱，也不自动启用恢复后的用户。查询失败、结果不完整、配置变化或租约失效时不应用该轮结果。日志记录成功时间与脱敏失败类型；失败不能被视为一次成功对账。

## 验证边界

控制面测试涵盖目录传输分类、配置、原子关联、登录、切换、对账和账号只读规则；SQLite/模拟目录只能证明这些本地规则。真实 MySQL 行锁和并发、群晖状态与 ACL、TLS 证书及生产网络可达性必须另行验证。未完成上述验证时，不应将默认未验证开关改为已验证。
