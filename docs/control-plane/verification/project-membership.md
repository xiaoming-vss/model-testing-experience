## 交付边界

普通成员没有绑定管理权限；Owner 也不能借用其他成员凭据。所有实时外部访问与异步凭据交付都须通过实际操作人的授权检查。项目已保存资产按照项目角色读取。

没有执行线上部署、账号授权配置或外部仓库修改。前端应按接口契约接入角色能力、成员管理和个人连接选择。
