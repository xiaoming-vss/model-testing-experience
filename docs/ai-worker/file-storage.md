# S3 任务文件读取

Worker 保留原平台任务文件入口，在实际下载时发送 `Accept: application/json`。S3 文件得到短期 URL、大小和 SHA-256 后，使用独立 HTTP 客户端下载，不携带 `X-Worker-Token`。UI 生成以仓库画像 pin 为源码，不再下载源码归档；历史 ZIP 归档下载路径已随旧数据清理删除。需求文档继续使用签名下载方法，只接受 JSON 票据，旧本地二进制响应会报错。

下载验证大小和哈希，网络失败或过期最多重试三次且重新申请票据；校验失败和对象不存在直接失败。文件随后写入任务临时目录；需求文档直接读取。长期 S3 密钥不配置到 Worker，签名 URL 不写入日志和任务快照。

部署时与控制面同时升级，并验证 Worker 到 S3 Endpoint 的网络连通。配置参见 [统一存储](../control-plane/file-storage.md)。
