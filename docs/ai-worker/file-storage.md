# S3 任务文件读取

Worker 保留原平台任务文件入口，在实际下载时发送 `Accept: application/json`。S3 文件得到短期 URL、大小和 SHA-256 后，使用独立 HTTP 客户端下载，不携带 `X-Worker-Token`。需求文档和 UI 源码归档共用签名下载方法，只接受 JSON 票据，旧本地二进制响应会报错。源码包按运行快照的文件 ID 下载，任务替换源码包不改变已启动运行的输入。

下载验证大小和哈希，网络失败或过期最多重试三次且重新申请票据；校验失败和对象不存在直接失败。文件随后写入任务临时目录，源码 ZIP 经路径检查后解压供技能使用。长期 S3 密钥不配置到 Worker，签名 URL 不写入日志和任务快照。

部署时与控制面同时升级，并验证 Worker 到 S3 Endpoint 的网络连通。配置参见 [统一存储](../control-plane/file-storage.md)。
