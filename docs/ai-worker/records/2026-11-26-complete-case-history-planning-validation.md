# 完整用例历史覆盖验证

- 验证日期：2026-11-26
- 设计记录：[控制面 ADR 0038](../../control-plane/adr/0038-plan-complete-cases-with-history.md)

## 真实模型回放

使用当天从平台导出的默认 Skill 副本、平台已有授权的 Pi 模型连接和独立工作目录。复用测试样例涵盖两路测试点等价、上限边界、条件主体不同、断言只覆盖一部分，以及待修订和旧阈值失效。独立复核发现模型将「导出任务已完成」等同于「源记录已完成」。明确条件主体和双向断言等价后复测，七个输入点形成六组，一个复用组、一个待修订组、四个待生成组。只覆盖部分断言的两个点均留在生成清单。

两段 Skill 联动回放使用已产生的真实历史核验的两个批次、保存的材料整理和两条按材料构造的功能测试点。两个模块共生成七条用例。评分一致性场景只生成一条，关联一个功能测试点和两个历史补测点；旧用例返回一条建议失效。用例通过目标引用和模块范围检查。审阅发现初稿从历史补测点推导出未记载的页面编辑操作，修订后以测试数据状态做对照。

## 自动和浏览器验证

- AI Worker 全套 unittest 通过，共 544 项，5 项外部集成用例跳过。功能用例专项覆盖全复用零生成、待修订截留、来源保留和遗漏拒绝。
- 控制面静态检查及候选工作流、来源闭包和 Worker 契约通过，共 41 项，覆盖带历史和无历史的试生成、采用、图谱与导入。另在新建的隔离 MySQL 库通过 12 项链路锁、完成回传和候选存储回归。
- Studio `npm run verify` 通过，217 个测试文件共 1144 项。Chrome 验证浅色桌面和深色窄屏的零新增用例及三类历史核验结论。

真实历史核验已采用的运行和测试点版本须配套。模型回放使用保存的历史结果，保留当前需求和正式用例状态。
