# 基础服务 MCP 配置


基础服务新增 MCP Tab（`/base-services?tab=mcp`），默认展示系统自带的禅道 MCP。
项目所有者首次填写名称和 MCP 服务 URL，成员分别保存自己的 token。配置协议固定为
`streamableHttp`，授权固定使用 `headers.token`，不提供自定义模板或启停操作。

页面显示“未配置服务”“本人未授权”“本人已配置授权”；已配置授权不代表远端连接
验证成功。URL 保存后不可编辑，仅支持重命名；更换地址须删除后重新配置，所有成员
重新授权。撤销个人授权不影响其他成员。token 不进入目录数据或查询缓存。

本期仅配置管理，尚不绑定 AIWork 任务类型或自动写入 nanobot。
