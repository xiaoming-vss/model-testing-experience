# 需求材料对照视图

2026-10-07，用户从三版原型中选择 B「材料对照」。需求分析第一阶段的材料提取产物，在查看和人工审核窗口中采用同一对照视图。

左侧按材料来源展示提取出的章节、正文、列表、表格及图片说明；右侧展示全部事实或待确认问题。事实保持原始顺序，可搜索并按确认状态筛选。点击事实或展开问题，会切换到包含相关材料的来源并突出对应内容块；多来源事实也可以通过来源摘录切换。点击已选事实可以再次定位。

材料来源通过选择器切换，来源信息按钮显示已登记的名称、类型、版本和位置。没有内容块的用户确认来源显示空材料提示，已有摘录仍在右侧可读。未知、不适用、冲突和示例状态保持原有含义。表格合并单元格、图片可见文字和问题详情复用领域产物阅读器。

原始 JSON 继续承担编辑；保存、审核通过并继续、继续优化沿用现有流程。视图不自动答复问题或确认业务事实；新输出的问题闭环规则见本文末尾。第二阶段默认展示模块与操作，按功能概况、业务流程、业务规则、待确认问题切换；左侧可以核对已审核材料及提取事实，详见 [需求理解对照视图](requirement-understanding-comparison.md)。

## 实现与检查

源码路径相对 apps/studio/src：

- features/ai-testing/components/RequirementMaterialComparison.tsx：两侧查看与定位。
- features/ai-testing/utils/materialComparison.ts：材料解析、引用关联与定位来源选择。
- features/ai-testing/styles/material-comparison.css：组件自持样式与容器响应布局。
- domain/requirements/RequirementArtifactView.tsx：完整产物及单个内容节点共用渲染。

宽容器采用并排两列，宽度小于840px（含窄屏和优化侧栏挤压）时上下排列。两侧内容独立滚动，审核操作由外层弹窗固定。窄屏对照区可用滚轮或键盘访问上下两块。

组件与引用关联测试覆盖全部事实、示例/未知状态、真实表格、多来源定位、图片文字、问题影响与答复、搜索、非法 JSON。相关页面、领域阅读器及布局测试共34项通过；ESLint、类型检查、主题检查和生产构建通过。

使用真实页面及同一份实际提取快照，在1680×1000浅色审核、深色只读和760×1000窄屏核对了滚动、来源定位与固定操作栏。业务请求为隔离的GET快照，验证未提交真实审核或保存。截图记录在仓库根 .scratch/material-extraction-preview/implemented/。

2026-10-07 问题闭环规则：两阶段业务阅读只展示尚未解决的问题和剩余缺口，计数只包含未解决条目；没有待确认问题时隐藏分类，当前分类自动回到事实或模块。旧产物中的 resolved 条目及其关联问题提示不进入业务阅读，原始 JSON 编辑仍保持输入原貌，需通过继续优化补齐正文并返回新契约。新生成、保存和审核后的产物不保留已解决问题及关联引用；答复依据保存在对应业务事实的来源引用中。未答复的问题与相关未知状态仍保留。

2026-10-07 继续优化预填：首次打开当前运行阶段的优化侧栏时，从当前产物草稿提取尚未解决的问题，按原编号逐题生成“答复”占位。材料提取与需求理解均适用；历史已解决问题不带入，无待确认问题时留空。取消后重新打开及提交失败保留已填写草稿。仅依据明确补充的信息修订，未填项继续待确认；原样模板不能提交，支持直接改写为其他优化要求。沿用阶段修订接口，同时携带左侧未保存的产物修改。
