实际数据与核对结果：

- 默认侧栏显示当前采用 `457ade72`，材料概况为 8 个章节、60 条规则、3 个待确认；其他候选为 `497bc31a` 和 `c56c732f`，数量显示 2 个。
- 选中候选 `497bc31a` 后，正文切换为该候选的 41 条说明，侧栏概况变为 8 个章节、41 条规则、3 个待确认，其他候选显示 1 个。
- 默认查看当前内容时，聚焦卡直接展示当前采用标识、生成时间和概况，不再重复显示同一条“当前采用”入口；选中候选时才出现“当前采用”行用于切回当前内容。
- 侧栏头部只显示阶段标题，实测高度 46px；阅读态不设返回按钮，返回通过页面面包屑的上级需求完成；内容区顶部保留 16px 间距，首张卡片不再贴住头部，长阶段名称也不再被截断。
- 聚焦卡不再展示“切换版本”和“与当前上游不一致”标签：版本通过其他候选磁贴切换，上游对齐在“来源与状态”卡查看。同一轮复验在 API 用例设计阶段（当前 `4bd3d04d`，其他候选 `41a64f98`、`b667c8e3`）确认聚焦卡同样没有这两项，来源与状态卡仍显示上游对齐为“不一致”。
- 侧栏不再显示静态的“生成流程”阶段说明，阶段信息由聚焦卡和来源状态承担；阶段被上游阻塞时仍保留阻塞原因提示。
- 选中候选后，底部“检查并采用、更多操作、编辑或派生、继续优化”固定在侧栏底部；内容区独立滚动。
- 生成新候选说明在 304px 宽度下显示两行；来源、最近生成和状态信息没有横向溢出。
