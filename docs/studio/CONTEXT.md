# Studio

MTX 管理测试生成任务从候选产出、采用确认到正式测试资产落库的生命周期。

## Language

**候选结果**：
生成任务成功产出的、尚未被采用为当前内容的不可变测试用例集合。候选可以比较、编辑派生或作为试生成输入，但只有显式采用后才成为下游默认读取的当前内容。
_Avoid_: 正式用例、导入结果、草稿版本

**资产库**：
Studio 顶部一级导航中的测试资产入口，包含用例库、接口库、软件仓库三个页签；「软件仓库」页提供项目级软件仓库管理，接口库左侧软件仓库树仅作分组导航，不提供软件仓库维护入口。旧 `/test-cases` 与测试页的 library/functional 链接统一跳转到资产库。
_Avoid_: 测试资产页、资料库

**接口库**：
资产库中的项目级接口定义工作区，打开后直接进入左侧软件仓库折叠树 + 右侧接口编辑器；接口定义用于后续生成测试用例，不包含 API 测试用例的发送、断言和执行记录。
_Avoid_: 接口用例库、API 测试集

**软件仓库**：
接口库左侧软件仓库树中的分组单位，固定对应一个 Git 仓库，包含名称、说明、仓库级 base path 和归属接口；软件仓库统一在「软件仓库」页维护，接口库内只作为分组使用，不能创建、编辑或删除。普通成员可在需求中关联并维护各自的工作分支与基线分支。
_Avoid_: 接口应用、应用、接口项目、API 集合

**接口分组**：
接口库软件仓库下的标签分组，由接口首个标签派生，也可在接口库中手工创建；手工分组名保存在软件仓库上，允许暂时没有接口并在刷新后继续显示。分组可折叠、重命名、移除，接口可通过移动操作归入目标分组。
_Avoid_: 接口应用、目录、文件夹

**UI 生成源码配置**：
UI 测试分组中的源码配置，选择仓库画像版本、前端仓库、commit 模式（画像 commit 或分支最新 HEAD）和来源正式功能用例。仓库画像版本是硬前置；启动时冻结仓库、分支、commit、画像版本和用例。没有成功画像版本或前端仓库时阻止启动并引导处理。
_Avoid_: 源码包、源码 ZIP、上传源码

**生成来源**：
运行和版本展示的冻结输入身份：仓库、分支、commit、commit 模式、画像版本及来源功能用例。来源追溯不展示克隆地址、连接 ID、凭据或 Worker 下载地址；commit 漂移通过“检查更新”显式查看。
_Avoid_: 源码文件、源码包快照

**采用**：
将某个候选结果设为阶段当前内容的独立业务动作，不代表正式资产已经创建。同一阶段只保留一个当前内容；采用时校验该候选自身的冻结来源闭包和根输入，不要求上游当前内容保持一致。
_Avoid_: 审核、批准、导入、确认导入

**正式资产导入**：
将当前采用的阶段内容写入一个或多个正式测试集合或套件的独立业务动作。
_Avoid_: 审核通过、批准

**冲突预览**：
正式资产导入前展示同名正式用例与候选用例差异、且不写入正式资产的确认状态。
_Avoid_: 导入失败、已导入

**需求质量档案**：
以迭代需求为主线，持续关联需求说明、代码变更、缺陷、测试资产、执行证据及质量分析记录的质量上下文集合。执行证据来自本需求用例所属测试单的执行结果，属于派生关联：引用自用例库、原本属于其他需求的用例，其执行结果不会归入本需求。
_Avoid_: 会话记录、测试报告、需求附件

**人工检查点**：
多阶段 AI 任务在进入下一阶段前暂停并等待人工确认或修订的控制点，不代表候选结果已经被采用。
_Avoid_: 审核、正式资产导入

**需求评审报告**：
需求分析首阶段生成的提示性结构化报告，页面以只读方式展示。字段和业务边界以[控制面上下文](../control-plane/CONTEXT.md)的「需求评审报告」为准；报告只供人工判断，不阻断材料整理，也不传给下游。
_Avoid_: 需求理解、材料整理结果

**材料整理结果**：
需求分析第二阶段采用的当前结构化材料，包含流程、规则、操作、交互及待确认问题，是功能用例生成复用的上游需求输入。需求分析包含提示性需求评审和材料整理两个相互独立的阶段。
_Avoid_: 原始 PRD、临时分析结果、功能用例

**GitLab 个人连接**：
项目成员为访问 GitLab 代码仓库配置的本人连接；软件仓库直接选择连接、群组和代码仓库，实时访问始终使用操作人的同实例个人授权。
_Avoid_: GitLab 群组绑定、项目共享 GitLab 连接

**项目共享服务**：
项目成员共同可见的基础服务配置，包含名称、地址及模型，不包含个人凭据；所有者创建后，成员各自授权才能使用。
_Avoid_: 共享授权、共享账号

**个人授权**：
用户本人保存的基础服务连接。其他成员包括项目所有者均不能使用；每次人工执行、阶段推进或重试选择当前操作人的授权。
_Avoid_: 共享连接、接管

**性能测试集**：
项目级性能测试资产，按顺序组织多条性能用例。一次测试集运行逐条串行执行测试集内的全部用例，前一条结束后才开始下一条；测试集本身不产生 k6 结果，跨用例不共享变量。资产字段与运行生命周期以[控制面上下文](../control-plane/CONTEXT.md)的「性能测试集」「性能运行」为准；本条描述 Studio 的编辑和展示职责。
_Avoid_: 性能分组、并行场景

**性能用例**：
性能测试集内的 k6 用例资产，拥有一个负载模型和多个按顺序执行的 API 步骤。详情页通过表单维护基本信息、负载模型、API 步骤和数据引用；表单生成内部 YAML 运行契约，YAML 仅用于排查和与 Worker 契约对照，不作为普通用户编辑入口。提取变量只在当前用例的当前 VU / 当前迭代内共享。
_Avoid_: 性能脚本、k6 文件

**用例失效**：
正式功能、API、UI 或性能用例的可恢复生命周期状态。管理列表默认显示全部，用内容区紧凑胶囊筛选「全部 / 有效 / 已失效」，失效用例显示橙色「已失效」标签；API/UI/性能共用「管理用例状态」弹窗，功能用例库沿用勾选条。选择与生成类弹窗只列出有效用例；失效用例不能发起新运行或调试，筛选态禁用拖拽排序。语义以[控制面上下文](../control-plane/CONTEXT.md)的「用例失效」为准。性能运行弹窗只展示有效用例并提示已排除数量。
_Avoid_: 删除、停用、禁用用例

**性能监控接入**：
基础服务中的项目级 Prometheus Remote Write 共享配置，包含写入地址、写入认证和启用状态。性能运行发起时选择接入；只冻结非敏感快照，凭据始终留在后端和 Worker。本期不提供查询配置或外部看板。
_Avoid_: 监控环境、监控看板连接

**性能运行**：
一次性能**测试集**执行的控制面记录，包含父运行和按顺序排列的子用例运行。父运行冻结测试集名称、环境、监控接入快照和逐用例状态；每个子运行冻结用例版本、YAML 和数据文件。页面展示逐用例执行事实与 k6 摘要，本期统一「未判定」，不提供平台内趋势图或外部看板入口。控制面记录的生命周期和字段以[控制面上下文](../control-plane/CONTEXT.md)的「性能运行」为准；本条描述页面展示。
_Avoid_: 压测报告、监控图表

**项目角色**：
后端返回的所有者、普通成员、只读成员、开发成员及可用操作。只有所有者维护成员、设置、项目技能和外部绑定。

**开发成员**：
在当前项目仅使用 Bug 模块的成员，可查看 Bug 与附件、评论、转派和更新状态；不能创建或编辑 Bug 基本信息，也不能访问需求、测试资产、执行记录或测试设计。项目切换后按新项目角色重新确定可见功能。
_Avoid_: 全局开发账号

**基线**：
代码风险分析在需求关联软件仓库时强制选择基线分支，且不能与工作分支相同；迭代代码变更概览直接使用各关联上的显式基线，不从历史迭代推断。
_Avoid_: 基准分支、对比起点

**代码风险分析**：
独立 AI 任务类型（可重复发起）。建 run 时固化各仓库的基线/工作分支 commit，Worker 准备独立代码工作区并让模型用只读工具读取；分析 skill 就绪前先展示上下文回执（预览），正式输出为变更概览/风险点清单/受影响用例/覆盖缺口四区块报告。
_Avoid_: 代码审查、风险检测

**仓库画像**：
生成全景中需求分析分组内第二行居中略偏左摆放的仓库画像卡片，与阶段卡片同尺寸、同状态样式和运行态动画，人工运行。每次成功运行形成一个不可变画像候选，采用后成为当前画像；单击进入与阶段产物一致的画布内阅读区，在阶段侧栏选择画像候选并查看上游/关联软件仓库；进入阅读区后运行或重新生成位于侧栏，主阅读区只展示画像内容。系统只读分析该需求全部关联软件仓库，默认使用最新已采用的材料整理内容，展示仓库角色、一句话职责及可展开的技术栈/目录/置信度/证据；画像不作为生成链阶段，但作为 UI 分组的源码前置，同时通过画布连线表达 API 与 UI 共用软件仓库上下文：材料整理的右侧出线绕行进入画像左侧，画像卡片再向 API 与 UI 分组出线。UI 测试分组只读取当前画像中的前端仓库角色、分支和 commit 作为源码配置项，API 仍使用接口库中选中的接口，画像正文不进入 API 或 UI 生成内容；API 侧栏展示画像识别出的后端／全栈仓库建议，接口选择器默认以这些仓库缩小范围，但可切换到需求关联软件仓库或项目全部接口，建议不构成生成限制；选择器支持按接口标签筛选，并与软件仓库筛选共同决定全选范围；不提供导入或发送操作。画像内容与生成边界以[AI Worker 上下文](../ai-worker/CONTEXT.md)的「仓库画像」为准，控制面任务字段见[控制面上下文](../control-plane/CONTEXT.md)的「仓库画像任务」；本条描述生成全景中的展示与拓扑。
_Avoid_: 代码风险画像、仓库分析阶段

**Bug 状态**：
激活、已解决、已关闭三个主状态，确认情况与解决方案分别展示；重新激活保留在处理历史中。延期处理属于未关闭的问题，不归为最终拒绝。
_Avoid_: 六状态机、已解决即已修复
