# API 运行归属与验证

API 用例运行和集合运行通过集合→需求→迭代推导当前项目归属。需求移动后，历史运行的访问权限与当前项目保持一致；删除资产时同步清理所属运行记录。关联缺失时拒绝访问，不再使用开发期间的归属归档表。

新库初始化见 [ADR-0006](../adr/0006-fresh-database-baseline.md)。数据库保留运行结果、请求快照、响应和变量；移除的是旧库迁移及归档路径。

验证入口：`tests/test_api_run_scope.py`，覆盖单用例/集合运行、Worker 回传、报告、归属移动后的权限与统计、硬删除清理和断链拒绝访问。初始化及模型一致性见 `tests/test_initial_schema_migration.py`。
