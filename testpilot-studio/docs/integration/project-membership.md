# 项目协作与个人授权前端接入

对应后端 `testing-agent-control-plane` 的 `docs/api/project-membership.md` 与 ADR 0007。

## 页面行为

- 项目总览显示当前角色，提供成员列表。所有者可按准确用户名添加已注册成员、调整角色、移除成员、转移所有权；非所有者可退出。
- 使用后端项目响应的 `permissions` 判断操作，不在前端维护第二套角色策略。权限未知时禁止修改；成员、项目设置、技能维护和外部绑定要求 `manage`。
- 需求、用例、API/UI 测试、AI 任务的按钮、菜单、提交弹窗及持久化排序受对应能力控制。详情页使用资源所属项目，避免把顶部当前项目权限用到其他项目。
- 无权限的操作入口保留并置灰，在按钮悬停或键盘聚焦时说明原因；点击不会打开操作弹窗或确认框。项目、迭代和需求的外部绑定入口要求 `manage`；成员列表和候选结果等合法只读查看仍可使用。
- 项目权限每 30 秒及窗口重新聚焦时更新；业务接口返回 403 后刷新权限和项目列表。详情失去读取权限时隐藏缓存内容。登录身份改变时清除所有查询缓存及工作台选择。

## 个人授权

- 基础服务展示项目共享服务目录及当前用户自己的授权状态。所有者先创建不含凭据的服务，再由每位成员分别授权；未授权也可查看配置。
- 创建、重命名和删除服务仅限所有者；“我的授权”仅提交本人的 API Key、Token 或账号密码。撤销授权不影响其他成员。
- 服务地址和模型用于确定授权对象，创建后固定；更换时新建服务并重新授权。旧个人连接查询继续用于执行选择器，不返回其他人的凭据。
- GitLab、禅道绑定展示 `instanceUrl`。同实例唯一有效本人连接可自动选择，多连接要求显式选择；不读取绑定历史 `connectionId` 作为凭据来源。
- 原 GitLab“接管”改为当前所有者使用本人同实例授权重新验证。禅道修改通过 PATCH 验证并更新，避免先解绑再创建导致失败时丢失原关联。
- 需求仓库选择按连接和仓库 ID 区分不同实例；分支及基线请求携带选定的本人连接。
- 代码概览支持逐实例选连接；实时请求的查询键包含选择结果，失败条目不显示统计数字。
- 人工 AI 阶段审核推进、优化、重试携带当前人的 `llmConnectionId`；唯一可用连接可自动选择，多条时出现选择弹窗。拒绝阶段不会额外索取 LLM 授权。
- 代码风险分析按需求绑定实例逐项选择本人 GitLab 连接，提交 `gitlabConnectionIds`；不会合并不同实例的相同仓库 ID。
- 禅道用例导入按需求绑定实例选本人连接，日报生成按迭代绑定实例选本人连接。

## 密钥与撤权

环境变量编辑保留 `********` 的“未修改”语义；已标记秘密不能取消秘密标记。只有秘密保存者可以修改和使用，其他成员应建立自己的执行环境。服务端负责最终验证和脱敏。

账号注销提示先转移或删除拥有的项目；退出或移除提示未完成任务会失败。前端不提供接管别人凭据的补救路径。

## 验证

新增 `ProjectMembership.test.tsx` 验证三角色、跨项目权限、成员添加、转移和撤权隐藏；`personalConnections.test.ts` 验证实例匹配、唯一选择、显式选择和失效连接。

既有 AI 与绑定交互测试同步了当前用户项目权限、实例身份和本人 LLM 连接字段。浏览器以独立本地模拟接口检查了所有者与只读成员的项目页、成员弹窗，未操作真实账号或项目。

### 执行结果

- 全量测试：38 个文件、222 项通过。
- 补充只读候选查看测试通过，确认不能批准或保存；最终受影响页面回归 103 项及 GitLab 绑定回归 2 项通过。
- `npm run verify`（类型检查、lint、生产构建）通过；构建保留现有的大文件分包提示。
- 浏览器验证使用独立本地模拟接口，覆盖所有者与只读成员的项目页和成员弹窗，不涉及真实账号授权或项目变更。

### 共享服务与个人授权拆分

新增 `SharedServicesPanel` 与共享目录 API：创建表单不包含凭据，授权表单单独处理本人的凭据，
关闭后清空；凭据不进入 React Query 的查询或 mutation 缓存。执行选择器继续读取个人连接，
授权更新与撤销后刷新对应缓存。服务列表在项目权限失效时隐藏。

本轮全量测试 39 个文件、226 项通过；补充弹窗回归 3 项通过。类型检查、lint、构建通过。
浏览器以独立模拟接口验证所有者与只读成员的共享目录及两种独立表单。

### 无权限操作的交互统一

无权限操作使用统一按钮组件禁用，并通过悬停或聚焦提示原因；禁用按钮阻止点击向卡片或确认框冒泡。绑定入口要求管理权限，删除了绑定弹窗的只读权限提示；服务管理、成员管理和候选审核操作保留禁用入口。

全量回归 226 项通过，1 项旧按钮名称精确匹配断言失败；修正后共享服务与 UI 候选回归 44 项通过，功能候选页面另行回归通过。类型检查、lint、生产构建及 diff 空白检查通过。
